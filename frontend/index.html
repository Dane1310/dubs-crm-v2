Agent / employee leaderboard

One card per agent — Daily / Weekly / Monthly toggle on each. Whoever you add to Active agents shows up automatically; whoever you mark as left disappears. Weighted score = Emails 20% · Adherence 15% · Client response 15% · Conversion 25% · Cadence follow-up 15% (Calls carries 10% but is excluded and the rest re-normalised to 100% until real call data exists, so a missing metric never fakes a result). No conversion is shown as a counter-metric next to Conversion, not scored separately, so it can't double-penalise.

Discipline & warning reference two LRA tracks, template letters — visible to owners only

Track A — Poor performance / incapacity (LRA Schedule 8, Item 9)
For an employee trying but not meeting standard. Requires: standard was known, fair opportunity to improve, real support given.
StepWhat happens
1. Counselling / 1:1Informal, standard clarified, documented
2. CoachingStructured support, specific gaps addressed
3. PIPWritten plan: targets, timeframe, support, review date
4. PIP reviewImproved → close out. Not improved → next step
5. DismissalOnly after a fair, fully documented process
Track B — Misconduct, including gross misconduct (LRA Schedule 8, Items 3–6)
For breaking a rule. Normally progressive; gross misconduct (theft, fraud, serious dishonesty, gross negligence) can justify skipping to a disciplinary enquiry — still requires a fair hearing.
StepWhat happens
1. Verbal warningFirst, minor offence — written down at the time regardless
2. Written warningRepeat, or slightly more serious offence
3. Final written warningFurther repeat, or a more serious single offence
4. Disciplinary enquiryFormal hearing, right to representation
5. DismissalOutcome of the enquiry, if warranted
Gross misconductMay justify skipping straight to Step 4
